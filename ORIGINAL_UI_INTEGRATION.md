# Original Interface Integration

This edition preserves the visual language and original supplied screens while connecting them to the Laravel API.

## Preserved interface assets

- Original landing page
- Original login and registration designs
- Original green sidebar, typography, colors, cards, tables, forms, and administrative visual language
- Original React/Figma and static HTML source files under `frontend-source/`

## Connected functionality

- Laravel Sanctum registration, login, logout, and authenticated profile
- Dashboard data
- Task CRUD and completion
- Habit CRUD and daily ticks
- Journal CRUD
- Mood check-ins
- Notifications
- Admin statistics and user status management

## Runtime frontend files

- `resources/views/original/`
- `public/js/original-app.js`
- `public/css/original-overrides.css`

No npm build is required for the integrated edition.
