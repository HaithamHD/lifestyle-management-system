§ 2 · Design phase

All 8 pages rendered as standalone HTML using the same design language as the existing React homepage (Playfair Display + DM Sans + DM Mono; dark-green primary #1a3d2b, orange accent #e05c3a). Captured at 1920 px width via headless Chrome.

  • Home page — editorial hero, stats bar, four-pillar section, testimonials, CTA, footer
  • Login & Register — split-screen with editorial image + testimonial quote pane
  • Dashboard — sidebar layout, 4 stat tiles, line chart (habit consistency), donut chart (time balance), tasks & habits panels
  • Tasks — filter tabs, quick-add with natural-language date parsing, morning/afternoon/evening groupings
  • Habits — weekly matrix (6 habits × 7 days) plus 52-week year heatmap
  • Journal — two-column layout: editor + mood picker on the left, recent entries + monthly mood chart on the right
  • Admin — system stats, user table with role/status/streak, live activity log, issue tracker

§ 3B · Design patterns

Four patterns are implemented as real code, each documented in the exact format the assignment requires (name / purpose / why chosen / implementation / screenshot).

PATTERN 1

Repository

Controllers depend on TaskRepositoryInterface, never on Eloquent directly. Persistence can be swapped in one line.

app/Repositories/ · 3 screenshots

PATTERN 2

Observer

TaskObserver reacts to lifecycle events. Marking a task complete auto-fires a notification via the Strategy channel — controllers stay thin.

app/Observers/TaskObserver.php · 2 screenshots

PATTERN 3

Factory

Model factories with named states (admin(), suspended(), completed(), overdue()) — the canonical Laravel implementation of the Factory pattern.

database/factories/ · 2 screenshots

PATTERN 4

Strategy

Three interchangeable notification channels behind a single interface: Email, Push (Firebase FCM), SMS (Twilio). Adding a fourth = one class + one match arm.

app/Services/Notification/ · 3 screenshots
